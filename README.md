# Meme Generator NFT

A web application experiment combining a meme editor with an NFT-oriented marketplace concept.

The project explores a more product-oriented frontend than my usual backend work: creating content, editing it, storing it, and presenting it through a marketplace-style interface.

## Demo

[Live demo](https://meme-gen-ltw.vercel.app)

## Features

- create and edit memes
- image/template based editing
- personal meme library
- marketplace-style browsing
- wallet-oriented interaction concept
- NFT minting concept

## Stack

- React / Next.js
- Tailwind CSS
- MongoDB
- IPFS-oriented asset storage
- blockchain/NFT experiment

## Run locally

```bash
git clone https://github.com/trandat1114/MemeGen-LTW
cd MemeGen-LTW
pnpm install
pnpm dev
```

## Project status

**Experimental project.**

The repository is kept as a record of exploring product design, web application architecture, and blockchain-related ideas. Some parts are prototypes rather than production infrastructure.
